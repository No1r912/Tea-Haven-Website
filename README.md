# 🍵 Tea Haven

A modern and responsive website for **Tea Haven**, a fictional tea and beverage brand concept based in Brunei. Designed to showcase a welcoming café experience through an elegant interface, smooth navigation, and a visually appealing layout.

## ✨ Features

* **Modern UI** — Clean and visually appealing design.
* **Responsive Layout** — Optimized for desktop, tablet, and mobile screens.
* **Product Showcase** — Presenting tea and beverage offerings.
* **Smooth Navigation** — Simple and intuitive browsing experience.
* **Brand Identity** — A cohesive visual style inspired by tea culture.

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/No1r912/Tea-Haven.git
```

### 2. Navigate to the Project

```bash
cd Tea-Haven
```

### 3. Run the Website

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code for local development.
